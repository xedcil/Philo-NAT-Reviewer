PILOSOPO: NAT PHILOSOPHY TRAINER (offline web app)

GitHub Pages (libre):
1. Sa github.com, himoa ang bag-ong repository, pananglitan "pilosopo-nat".
2. I-upload ang TANANG files niini nga folder (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png).
3. Settings > Pages > Source: "Deploy from a branch" > main / root > Save.
4. Maghulat og 1-2 ka minuto. Ang link kay https://USERNAME.github.io/pilosopo-nat/

Sa phone sa estudyante:
1. Ablihi ang link sa Chrome (Android) o Safari (iPhone) kung naay internet, kausa lang.
2. Android: menu > "Install app" / "Add to Home screen". iPhone: Share > "Add to Home Screen".
3. Human niana molihok na kini bisan walay internet. Ang progress gi-save sa phone.

Pag-update sa content: usba ang index.html ug usba ang "pilosopo-v1" sa sw.js ngadto sa "pilosopo-v2" aron mo-refresh ang cache sa mga phone.
Dili molihok ang offline install kung bukas ra ang file gikan sa folder (file://). Kinahanglan nga naka-host.
